## Blockers — all resolved (retroactively verified May 26)

### Security

- [x] **S1 — SSRF in AI service `base_url`** — **FIXED** (verified May 26)

  `app/auth_deps.py:77-83` now checks `user.totp_enabled` on Bearer path with `totp_verified` cookie verification.

  `app/auth_deps.py:29-37` adds `require_totp_or_recent_auth` dependency. Applied to all three sensitive endpoints in `app/api/settings.py:653,739,778`.

- [x] **S4 — docker-compose weak default DB password** — **FIXED** (verified May 26)  
  `docker-compose.yml:5-7` now uses `:?error:` syntax — fails fast on missing env var instead of defaulting to `expense`.

### Data Integrity

- [x] **D1 — Transaction cascade broken** — **FIXED** (verified May 26)  
  `app/models/transaction.py:43`: `ondelete="CASCADE"` added to `ForeignKey("emails.id")`.

- [x] **D2 — `user_id` nullable on financial models** — **FIXED** (verified May 26)  
  `app/models/financial.py`: Changed `nullable=True` → `nullable=False` for Budget, Debt, RecurringExpense, SenderRule, MerchantAlias, Goal.

### API

- [x] **A1 — LLM prompt injection** — **NOT A BUG** (verified May 26)  
  Single-email path correctly uses `_escape()` with `.format()`. Batch and filter paths use f-strings (not `.format()`), so `_escape()` is unnecessary. Finding was a false positive.
