MoneyFlow

Inbox for your money — automatically track expenses from Gmail using a rule engine + multi-provider LLM.

Overview

MoneyFlow syncs your Gmail inbox, classifies financial emails (bank alerts, invoices, receipts, UPI confirmations) using a two-stage pipeline — domain rules with fallback to a multi-provider LLM — and gives you a live dashboard of your spending without manually entering a single transaction.

Quick Start

🏠 Local mode (no external services)

git clone https://github.com/amansn7/GexpenseTracker-Public.git
cd GexpenseTracker-Public
bash scripts/setup-local.sh
source .venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Open http://localhost:8000 and click "Start locally".

🐳 Docker (local mode)

docker compose -f docker-compose.local.yml up --build

Open http://localhost:8000.

☁️ Cloud mode (Gmail sync)

cp .env.example .env
# Edit .env: set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET,
#            SECRET_KEY, FERNET_KEY, REDIS_URL
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export DATABASE_URL="postgresql+asyncpg://user:pass@localhost:5432/expense_tracker"
alembic upgrade head
uvicorn app.main:app --reload

Features

📥 Gmail Sync

Incremental sync using Gmail history IDs. 90-day fallback, configurable filters, manual re-scan with live progress polling.

🤖 Smart Classification

Rule engine (18 built-in vendors) + multi-provider LLM fallback (Gemini, Grok, Groq, Scaleway, OpenRouter, Cloudflare).

📊 7 Screens

Inbox, Money Flow (Sankey), Dashboard, Health, Reports, Recurring, Debt — all with category & date range filtering.

🧠 Auto-Learning

Fixing a transaction creates a domain rule. Bulk retrain, fuzzy merchant aliasing, auto-resolve duplicate pairs at ≥85% confidence.

🎨 3 Themes

Paper (warm cream), Cool (gray-blue), Midnight (dark charcoal). Cmd+K global search across everything.

🔒 Security

Google OAuth 2.0, optional TOTP 2FA, multi-user via email allowlist, bring your own LLM key.
