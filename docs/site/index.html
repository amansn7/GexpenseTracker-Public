Features
Everything you need

Built for Indian users but works globally. Understands UPI alerts, bank debits, GST invoices, and more.

📧

Gmail Sync

Incremental sync via Gmail history IDs. Only fetches new messages. Configurable filter: all / unread / read.

⚙

Rule Engine

18 built-in vendor domain rules + keyword scoring across expense, income, and ignore buckets. Zero LLM cost for known senders.

✦

Multi-LLM Fallback

Google Gemini → Grok → Scaleway → OpenRouter. Automatic rate-limit backoff. All free tiers supported.

🔍

Classifier Debugger

Terminal-style output shows every rule tested, every keyword matched, exact prompt sent, and raw LLM response received.

🎯

Inline Fix + Retrain

Wrong label? Fix merchant, category, amount inline. Save as a domain rule in one click. Retrain rules from selected emails.

📊

Dashboard & Budgets

Spending trend, category donut, top merchants, income vs expense — with a period picker and animated stat cards.

How it works
From inbox to insight

Four steps, fully automated after setup.

01

Connect Gmail

Authorise via OAuth. GExpense never stores your Gmail password — only a scoped refresh token.

02

Auto-Sync

Every 2 hours (configurable), new emails are fetched incrementally using Gmail history IDs.

03

Classify

Domain rules handle known senders instantly. Unknown emails go through an LLM with automatic provider fallback.

04

Review & Train

Low-confidence results surface in the review queue. Corrections auto-train domain rules for future accuracy.
