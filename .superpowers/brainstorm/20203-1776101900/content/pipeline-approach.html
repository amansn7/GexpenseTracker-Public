What does "LLM-first" mean for the pipeline?

Three interpretations — pick the one that matches your intent.

A

LLM Always First

Every new email goes to LLM immediately. Rules only run after to validate/correct. Highest accuracy, highest cost. Rules become a safety net, not a gate.

Email → LLM → Rule validation → Save
(Rules used only to catch LLM errors)
B

LLM-First with Rule Fast-Path (recommended)

Known senders (amazon.in, HDFC alerts, etc.) skip LLM — rules handle them instantly. Everything else goes to LLM. LLM outputs auto-generate rules, so the fast-path grows over time.

Email → Domain/Pattern match? → YES: Rule result
                           → NO: LLM → generate rule → save
C

Parallel (LLM + Rules simultaneously)

Both run at once. Rule result is preferred if high-confidence; LLM wins on conflicts. Fastest perceived latency, but doubles cost on every email that has a rule.

Email → Rules ─┐
            → LLM ─┴→ merge → save
