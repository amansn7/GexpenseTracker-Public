Section 2: Bootstrap Service

Group similar emails → one LLM call per group → rule covers the whole group.

Step 1 — Grouping Strategy
Primary key: sender_domain
Emails from the same domain are already about the same service. hdfc.co.in → all HDFC alerts grouped.
Secondary split: body fingerprint
Same domain may have multiple patterns (debit alert vs statement vs OTP). Split by 3-word keyword signature extracted from body.
Example grouping:
hdfc.co.in + "debited via upi" → Group A (12 emails)
hdfc.co.in + "credited to account" → Group B (4 emails)
hdfc.co.in + "one time password" → Group C (8 emails) → skip (OTP)
↳ 2 LLM calls instead of 24
Step 2 — Processing Flow
For each group:
1. Pick representative email
(longest body_text in group)
2. Send to LLM → classify + extract
3. Generate + validate rule
(template → LLM-written fallback)
4. Test rule against ALL emails
in the group (not just the rep)
5. Save rule if ≥70% match
6. Backfill transactions for
all matched emails in group

Batch size: 8 groups concurrent
Rate limit: pause if 429
