What's changing & why

🏗 Layout

  • Left sidebar replaces top nav
  • Review badge always visible
  • Sync button fixed at sidebar bottom
  • Main content full-width, more breathing room
  • Ambient glow orbs per page (matches dominant color)

✨ Animation

  • Sidebar nav: instant (0ms)
  • Stat numbers: count-up on mount (600ms)
  • Skeleton shimmer → fade on all data loads
  • Modals: scale(0.96)→1 + fade, 200ms ease-out
  • Budget bars: animate width on mount
  • Feed rows: staggered fade-in (30ms each)
  • Hover rows: translateY(-1px) + glow, instant

🎨 Glassmorphism

  • Cards: rgba(255,255,255,0.04) + blur(8px)
  • Sidebar: rgba(255,255,255,0.02) + blur(12px)
  • Modals: stronger blur(20px) backdrop
  • Borders: rgba(255,255,255,0.06–0.10)
  • Ambient orbs: blurred color blobs per page
  • Active nav: rgba(124,131,253,0.12) tinted

⚡ Performance / UX

  • Skeleton placeholders on every API call
  • Optimistic updates on edit save
  • Toast notifications replace alert() / page reload
  • Keyboard nav: Escape closes modals/tooltips
  • CSS custom properties for all color tokens

🔒 Scope

  • Zero backend changes
  • All APIs unchanged
  • Existing features preserved (hover preview, edit modal, sync panel)
  • New CSS replaces base.html inline styles
  • app.js extended, not rewritten

📄 Pages

  • Dashboard: activity-led, budget sidebar
  • Transactions: glass table, same columns
  • Review: card-stack with keyboard shortcuts
  • Recurring: clean glass list
  • Budgets: visual progress + edit inline
  • Settings: glass form sections
