Component Map
📅 APScheduler
Fires every 2hr
Triggers Gmail sync
📬 Gmail Client
OAuth2 auth
Fetches new emails
via Gmail API
🧠 Hybrid Classifier
Rules → confidence
Low confidence → LLM
Returns: expense/income/ignore
🔍 Extractor
Amount, merchant
date, category
currency, email link
🗄️ Postgres
emails table
transactions table
sync_state table
🌐 FastAPI + Dashboard
REST API
Web dashboard
Manual sync trigger
Data flow:
Scheduler → Gmail Client → Classifier → Extractor → Postgres
High confidence → auto-stored as confirmed
Low confidence → stored as "needs review" → shown in dashboard
User marks/corrects in dashboard → updates Postgres
All in one process. FastAPI app starts APScheduler on startup. Single docker compose up runs everything (app + postgres).
