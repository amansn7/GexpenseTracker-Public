Where does the email classification service run?

This shapes the entire architecture — pick what fits your lifestyle best

A

Local background service (your Mac)

Runs on your machine, polls Gmail periodically. Simple, private, no cloud costs. Stops when Mac is off.

B

Cloud function / serverless

Runs on AWS Lambda / GCP Cloud Functions / Vercel. Triggered on a schedule. Always on, no machine dependency.

C

Web app backend (self-hosted)

Full backend server with API + background worker. Enables future dashboard, mobile app, multi-user. Most work upfront.
