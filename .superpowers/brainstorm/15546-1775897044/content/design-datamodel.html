Hybrid Classifier Flow

Step 1 — Rule engine
  Check sender domain against known lists (amazon.com, paypal.com, stripe.com...)
  Keyword scan: subject + snippet → "receipt", "invoice", "order", "payment", "refund"
  → confidence score 0.0–1.0

Step 2 — Threshold check
  confidence ≥ 0.85 → auto-classify, skip LLM
  confidence < 0.85 → call LLM

Step 3 — LLM (Claude claude-haiku-4-5 for cost)
  Prompt: subject + sender + body snippet
  Returns: label + extracted fields + confidence

Step 4 — Store result
  confidence ≥ 0.75 → status: auto
  confidence < 0.75 → status: needs_review (shown in dashboard)
User training loop: When user corrects a classification in dashboard → correction stored → rule engine learns sender domain pattern for future emails. No LLM call needed for known senders after first correction.
