API Surface (FastAPI routes)

GET /api/transactions — list with filters (label, status, date range)
GET /api/transactions/{id} — single transaction + source email
PATCH /api/transactions/{id} — correct label/category/amount
GET /api/review — pending needs_review queue
GET /api/sync/status — last sync time, next sync time
POST /api/sync/trigger — manual sync now
GET /api/auth/gmail — start OAuth2 flow
GET /api/auth/callback — OAuth2 callback
GET /api/stats — monthly summary (income, expenses, by category)
