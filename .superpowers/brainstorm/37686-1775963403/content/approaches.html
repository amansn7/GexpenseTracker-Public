3 Approaches — Transactions Redesign

All three include: full body storage, 3s hover preview, proper edit modal, income visible. They differ in how much the table UI changes.

A

Surgical Fixes

Keep the existing table layout. Add the missing pieces on top: hover tooltip, edit modal, body_text storage, income row coloring.

Pros

  • Smallest changeset
  • Nothing breaks
  • Fast to ship

Cons

  • Table stays cluttered (Source column, Status column taking space)
  • No visual hierarchy between expense vs income
B

Refined Table ⭐ Recommended

Redesign the table columns for clarity. Drop noisy columns (Source → icon, Status → badge color). Add left-border color coding per label. Edit button becomes a pencil icon. Hover tooltip shows full body.

C

Card List

Replace table with a card-per-transaction layout (like the Review page). More space for each entry, easier to read on mobile. Merchant prominent, amount large.

Pros

  • Matches review page style
  • More breathing room per entry

Cons

  • Much less dense — harder to scan 100s of transactions
  • Big departure from current layout
